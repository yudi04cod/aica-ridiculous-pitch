An entry for [Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a) on make.fun: one sentence, at most 200 characters, pitching a bizarre startup idea that sounds absurd until you realise it would actually sell.

## How it works

`main.py` writes a single line to `/output/entry.txt`. The program is fully
deterministic — it produces byte-identical output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
